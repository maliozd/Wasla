# Mock fixtures / Örnek dosyalar

**EN:** JSON files in subfolders are **sanitized**, provider-shaped samples for reference and mock alignment. They are **not** loaded at runtime by default. Do **not** commit real customer data, phone numbers, full addresses, tokens, credentials, or real order IDs—use fake values and preserve response shape only.

**TR:** Alt klasörlerdeki JSON dosyaları **anonimleştirilmiş**, provider biçiminde referans ve mock hizalama örnekleridir; varsayılan olarak **çalışma zamanında yüklenmez**. Gerçek müşteri verisi, telefon, tam adres, token, kimlik bilgisi veya gerçek sipariş ID’si **eklenmemelidir**—sahte değerler kullanın, yanıt şeklini koruyun.
